# Grid Pathfinding Visualizer (DSA2-P030)

A C++ console application that compares pathfinding algorithms on a weighted 6x6 grid map[cite: 30].

## Features
- **Pathfinding Algorithms:** BFS (Queue), DFS (Recursion), and Dijkstra's Algorithm (Min-Heap Priority Queue) with step-by-step traversal and parent-pointer path reconstruction[cite: 30].
- **Terrain Record Management (CRUD):** Create, view, update, and delete 18+ weighted cell records with live grid synchronization and input validation[cite: 30].
- **Search & Sort:** Linear Search by Cell ID/Terrain Type and Selection Sort by movement weight[cite: 30].
- **Analytics:** Operation history log and Big-O Time/Space complexity comparison table[cite: 30].
